# 六面顶压机碳转石墨过程可视化系统

## 系统概述
本系统实现六面顶压机中碳转石墨过程的实时监控与控制，集成3D可视化界面与精确参数控制。

## 核心功能
- **工艺控制**：压力温度实时监控，精确控制
- **可视化**：3D模型实时显示，动态粒子效果
- **数据管理**：过程记录，参数导出
- **智能预警**：故障诊断，安全监测

## 技术参数
- **压力范围**：0-10GPa (±0.1GPa)
- **温度范围**：0-200℃ (±1℃)
- **显示屏**：128x64 OLED
- **控制器**：STM32F407VGT6

## 操作指南
- **按键功能**
  - ↑↓：菜单选择
  - OK：确认/进入
  - ESC：返回/取消
  - 长按：快速调节

## 步进电机配置
### 硬件接口
```
motor1 (TIM2 + DMA1_Stream6)
- A:PA10  B:PA11  C:PA12  D:PA15

motor2 (TIM3 + DMA1_Stream2)
- A:PA0   B:PA1   C:PA2   D:PA3

motor3 (TIM4 + DMA1_Stream7)
- A:PB3   B:PB4   C:PB5   D:PB6
```

### 性能参数
- 速度：10-1000步/秒
- 驱动方式：4相8拍
- 控制方式：DMA循环驱动
- 实时监控：位置、速度、状态
