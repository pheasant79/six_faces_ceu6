<a id="设备简介"></a>
## 1. 设备简介

六面顶菜单系统是一种专为碳转石墨过程设计的控制系统，基于OLED显示屏和按键操作界面。本系统提供了友好的用户界面，用于监控和控制六面顶石墨化过程中的压力、温度、时间等关键参数，并提供完整的工艺流程选择和监控功能。

### 1.1 主要功能

- 实时监控六面压力值和温度值
- 多种工艺流程选择与自定义
- 参数设置与调整
- 历史数据记录与查询
- 系统校准与配置
- 异常情况报警提示

### 1.2 应用场景

本系统适用于实验室和工业生产环境中的碳材料转化为石墨材料的压力辅助热处理过程，特别适合需要精确控制六个方向压力的应用场景。

<a id="快速入门"></a>
## 2. 快速入门

### 2.1 设备开机

1. 确保设备电源连接正确
2. 按下设备电源开关
3. 等待系统初始化完成（约5秒钟）
4. 系统启动后将显示主菜单界面

<div class="note">
注意：首次使用设备前，建议进行压力和温度校准以确保测量准确性。
</div>

### 2.2 基本界面介绍

开机后，显示屏将显示主菜单，包含以下几个主要选项：
- 工艺过程
- 设置
- 历史记录

<a id="基本操作"></a>
## 3. 基本操作

### 3.1 按键功能

本系统配备5个功能按键，各按键功能如下：

| 按键 | 功能 |
|------|------|
| 按键1 | 向上移动/增加值 |
| 按键2 | 向下移动/减小值 |
| 按键3 | 确认/进入编辑模式 |
| 按键4 | 返回/取消 |
| 按键5 | 特殊功能/快捷键 |

### 3.2 菜单操作基础

- **选择菜单项**：使用按键1(上)和按键2(下)移动光标
- **进入子菜单**：选中菜单项后按下按键3(确认)
- **返回上级菜单**：按下按键4(返回)
- **编辑参数**：选中参数后按按键3进入编辑模式，使用按键1和按键2调整值，再次按下按键3保存

<div class="warning">
警告：参数修改后必须按确认键(按键3)保存，否则修改将丢失！
</div>

<a id="菜单导航"></a>
## 4. 菜单导航

### 4.1 主菜单

主菜单是系统的起始界面，包含以下选项：

- **工艺过程**：进入工艺监控和控制界面
- **设置**：系统参数设置和配置
- **历史记录**：查看历史运行数据和记录

### 4.2 设置菜单

设置菜单包含以下子菜单：

- **压力设置**：调整各面压力参数
- **温度设置**：调整温度控制参数
- **时间设置**：调整工艺时间参数
- **工艺选择**：选择预设工艺或自定义工艺
- **数据记录**：配置数据记录参数
- **系统配置**：系统校准和其他配置
- **电机状态**：查看和控制电机

### 4.3 系统配置子菜单

系统配置子菜单包含：

- **压力校准**：校准六面压力传感器
- **温度校准**：校准温度传感器
- **警报配置**：设置警报阈值和响应方式
- **系统信息**：查看系统版本和运行信息

<a id="工艺过程"></a>
## 5. 工艺过程操作

### 5.1 启动工艺流程

1. 在主菜单选择"工艺过程"
2. 系统将显示当前工艺状态
3. 若要启动工艺，选择"启动"并按确认键
4. 系统将进入工艺运行状态

### 5.2 工艺状态监控

工艺运行时，系统将显示以下信息：

- 六面当前压力值
- 当前温度值
- 工艺进度百分比
- 已运行时间
- 当前工艺阶段

### 5.3 工艺流程暂停/继续

1. 工艺运行过程中，按确认键可调出操作菜单
2. 选择"暂停"可暂停当前工艺
3. 在暂停状态下，选择"继续"可恢复工艺
4. 选择"终止"可结束当前工艺

<div class="warning">
警告：工艺终止后无法恢复，请谨慎操作！
</div>

<div class="section-divider"></div>

<a id="系统设置"></a>
## 6. 系统设置

### 6.1 压力设置

在此菜单中可以设置各个方向的压力参数：

1. 进入"压力设置"菜单
2. 选择需要设置的面（X+, X-, Y+, Y-, Z+, Z-）
3. 设置目标压力值
4. 设置压力容差范围
5. 设置压力变化速率

### 6.2 温度设置

温度设置菜单允许配置以下参数：

- 目标温度
- 升温速率
- 保温时间
- 降温速率
- 温度警告阈值

### 6.3 工艺选择

系统预设了3种常用工艺流程，也支持自定义工艺：

1. **工艺1**：标准石墨化工艺
2. **工艺2**：高压石墨化工艺
3. **工艺3**：低温长时间石墨化工艺
4. **自定义**：用户自定义参数工艺

<div class="section-divider"></div>

<a id="历史记录"></a>
## 7. 历史记录查看

### 7.1 浏览历史记录

1. 在主菜单选择"历史记录"
2. 系统将显示按日期排序的历史工艺记录
3. 使用上下键选择记录
4. 按确认键查看详细信息

### 7.2 记录详情

历史记录详情包含以下信息：

- 工艺执行日期和时间
- 所用工艺类型
- 最高温度和各面最大压力
- 工艺总运行时间
- 工艺是否正常完成

### 7.3 数据导出

系统支持通过串口导出历史数据：

1. 在历史记录界面，按按键5
2. 选择"导出数据"
3. 连接计算机到设备的数据接口
4. 按确认键开始传输数据

<a id="警报系统"></a>
## 8. 警报系统

### 8.1 警报级别

系统具有两级警报：

- **警告（Warning）**：参数接近安全限值，系统继续运行
- **危险（Critical）**：参数超出安全范围，系统可能自动停止运行

### 8.2 警报响应

当触发警报时：

1. 显示屏将显示警报信息
2. 对应参数值将闪烁显示
3. 系统蜂鸣器发出警报声

### 8.3 警报处理

1. 按任意键可暂时静音警报声
2. 调整参数回到安全范围
3. 确认警报已解除后，系统将恢复正常显示

<a id="故障排除"></a>
## 9. 故障排除

### 9.1 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 系统无法开机 | 电源连接问题 | 检查电源连接，确保输入电压正常 |
| 显示屏无显示 | 显示连接问题或亮度设置 | 检查显示连接，调整亮度设置 |
| 按键无响应 | 按键卡顿或系统忙 | 重启系统，检查按键是否卡住 |
| 压力显示异常 | 传感器故障或校准错误 | 进行压力校准或检查传感器连接 |
| 温度显示异常 | 热电偶故障或连接问题 | 检查热电偶连接，进行温度校准 |

### 9.2 系统错误代码

| 错误代码 | 含义 | 处理方法 |
|---------|------|---------|
| E01 | 压力传感器通信错误 | 检查传感器连接，重启系统 |
| E02 | 温度传感器通信错误 | 检查热电偶连接，重启系统 |
| E03 | 电机驱动错误 | 检查电机连接和供电 |
| E04 | 系统过热 | 停止工艺，等待系统冷却 |
| E05 | 数据存储错误 | 备份数据，重置系统 |

<a id="维护保养"></a>
## 10. 维护保养

### 10.1 日常维护

- 保持设备外表清洁，定期用干布擦拭显示屏
- 检查按键是否灵敏，如有卡顿可用专用清洁液清洁
- 定期检查电源线和数据线连接是否牢固

### 10.2 校准维护

建议每3个月进行一次系统校准：

1. 进入系统配置->压力校准
2. 按照提示进行六面压力校准
3. 进入系统配置->温度校准
4. 使用标准温度计进行温度校准

### 10.3 软件更新

当有新版本固件时：

1. 下载最新固件到U盘
2. 系统关机状态下插入U盘
3. 按住按键5的同时开机
4. 按照屏幕提示完成更新
